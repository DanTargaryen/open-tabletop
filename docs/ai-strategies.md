# AI 策略与行为对比

本次调整解决了原先多个角色过于被动、行为差异主要来自小幅阈值变化的问题。现在根据位置、翻前加注者、当前街公开行动、听牌和有效筹码作出不同决策，保留三档采样难度。

## 五个角色

- **豆包：宽松跟进。** 较宽的起手范围和跟注倾向，更多参与牌局；有优势时会主动下注。
- **ChatGPT：位置进攻。** 倾向在后位争夺盲注，翻前主动后会选择持续下注，也有少量轻型再加注。
- **Claude：精选强攻。** 保留较精选的起手范围，拿到强牌时主动加注，下注尺度偏大。
- **GLM：主动施压。** 较宽的范围、高主动下注频率；并非每次都持有强牌。
- **DeepSeek：埋伏反击。** 听牌半诈唬更积极，少量强牌会过牌埋伏。过牌加注只依据本街最近的本人行动，不重复使用一次旧过牌。

## 固定场景结果

250 手六席练习桌；固定 seed；座位 0 总是能过牌就过牌，否则跟注，其他五席执行真实 `botAction()`。每手由引擎恢复 2,000 筹码、正常轮换庄位。这是描述性行为测试，不是对不同水平真人的胜率测试。

| 角色 | 入池率：旧 → 新 | 翻前加注手率：旧 → 新 | 翻后面对未下注底池的主动下注率：旧 → 新 |
| --- | --- | --- | --- |
| 豆包 | 20.0% → 40.0% | 6.0% → 13.2% | 32.0% → 50.3% |
| ChatGPT | 53.2% → 39.6% | 26.8% → 22.4% | 40.9% → 59.5% |
| Claude | 13.2% → 16.0% | 2.8% → 11.6% | 22.3% → 64.1% |
| GLM | 32.4% → 51.2% | 18.4% → 37.2% | 41.0% → 75.2% |
| DeepSeek | 16.0% → 25.2% | 5.6% → 16.4% | 38.0% → 42.5% |

入池率排除强制盲注；翻前加注按每手去重；翻后主动下注率只统计当前没有下注、同时可以过牌和加注的决策机会。ChatGPT 在更主动的对手面前减少了部分翻前跟注，其翻后主动下注率提高；并不是要求每个角色的每项指标都上升。

完整计数、分母、全押（含全押跟注）与筹码检查见 [旧策略数据](ai-baseline.json) 和 [新策略数据](ai-current.json)。各角色行为会互相影响，不能将某个指标的变化单独解释为实力提升。

## 重复测量

```sh
node games/texas-holdem/scripts/measure-ai.mjs --hands 250 --difficulty standard
```

可选 `--engine path/to/engine.mjs` 比较其他引擎文件，`--difficulty casual|standard|expert` 选择难度。旧策略来自提交 `9edd37653a8eac137d91dec1892a0bd8ebd7b283` 中的 `games/texas-holdem/web/engine.js`。测量脚本不干预 AI、不更改玩家身份，也不把统计时读取的隐藏状态传给决策。

## 保留的约束

- 判断听牌仅使用本人的牌和公牌；河牌不使用听牌半诈唬。
- 当其他玩家已经全押时，不假设能通过诈唬让所有对手弃牌。
- 投机加注受有效筹码、本人剩余筹码和每街次数限制；最小加注超预算时取消该加注。
- 弱牌面对多次加注，不会因只能短全押而自动全下。
- 所有行动仍通过同一个下注规则校验器；没有修改牌型、主池、边池或筹码守恒规则。
- 新增五角色 × 四街 × 三难度的隐藏牌置换检查，继续验证 AI 不消耗发牌随机流，存档恢复后可重复决策。
