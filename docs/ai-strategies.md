# AI 策略与行为对比

2026-09-16 调整：减少面对小加注就整桌弃牌的情况，让更多角色愿意看翻牌、争夺底池。单机和好友房 AI 共用同一策略。

## 这次改变

- 翻牌前只有一次或没有加注、需要补齐不超过 3 个大盲且不超过剩余筹码 8% 时，放宽继续范围，并给便宜看翻牌的手牌一个有限的参与补偿。多人摊牌胜率不会再成为唯一的小额入池门槛；这属于游戏风格，不是假称胜率增加。
- 翻后自己成对或有强听牌、只需付出当前底池至多 25% 且不超过剩余筹码 8% 时，更愿意继续。公牌本身成对不等于玩家自己有对子，河牌没有听牌补偿。
- 提高角色的后位偷盲、延续下注、半诈唬及部分价值进攻倾向，降低过度慢打。多次加注、大额投入仍检查牌力与价格。
- 投机加注仍有每街次数和有效筹码预算，不能因为最小加注过大就盲目深筹码全押。免费过牌不会弃牌。

## 五个角色

- **豆包：宽松跟进。** 最愿意跟便宜的注、参与多人底池，有优势会主动下注。
- **ChatGPT：位置进攻。** 更愿意防守小加注，利用后位偷盲、持续下注和选择性再加注。
- **Claude：精选强攻。** 相对更挑牌，但愿意用可玩的手牌看便宜翻牌；强牌仍主动取值。
- **GLM：主动施压。** 宽范围参与，不容易被小注赶走，并用偷盲和半诈唬施压。
- **DeepSeek：埋伏反击。** 更多同花连张跟进和听牌反击，减少无意义等待，保留少量过牌埋伏。

## 固定场景结果

250 手、标准难度、六席练习桌；固定 seed；座位 0 总是能过牌就过牌，否则跟注，五席执行真实 `botAction()`。每手恢复 2,000 筹码并正常轮换庄位。

| 角色 | 自愿入池手率：旧 → 新 | 面对便宜加注的弃牌率：旧 → 新 | 翻前加注手率：旧 → 新 |
| --- | --- | --- | --- |
| 豆包 | 40.0% → 77.6% | 55.2% → 13.8% | 13.2% → 21.6% |
| ChatGPT | 39.6% → 62.8% | 50.6% → 21.4% | 22.4% → 19.6% |
| Claude | 16.0% → 44.8% | 87.8% → 38.4% | 11.6% → 13.2% |
| GLM | 51.2% → 73.6% | 64.4% → 18.0% | 37.2% → 31.2% |
| DeepSeek | 25.2% → 64.0% | 80.9% → 20.2% | 16.4% → 18.0% |

每手进入翻牌的平均人数（含座位 0）由 **2.77 人增加到 4.04 人**。两组 250 手都到达翻牌；这个始终跟注的人类策略不能用于推断真人牌桌的翻前结束率。

入池率排除强制盲注，翻前加注按手去重。便宜加注指标以实际面临付费决策、前面至多一次加注、跟注额至多 3 大盲且至多剩余筹码 8% 的机会为分母，并非所有手牌。角色相互影响，所以参数更积极不保证每个角色的加注手率都提高。

这是固定场景的行为对比，不是胜率或实力证明。完整计数、分母、全押率和守恒检查见 [旧策略数据](ai-baseline.json)、[新策略数据](ai-current.json)。旧引擎来自提交 `64a090c69ece742d0417dbb91f839aa78e9c8bbe`。

## 重复测量与约束

```sh
node games/texas-holdem/scripts/measure-ai.mjs --hands 250 --difficulty standard
node --test games/texas-holdem/tests/ai*.test.mjs
```

可用 `--engine path/to/engine.mjs` 比较其他引擎，`--difficulty casual|standard|expert` 选择难度。脚本只观察真实行动，不干预决策或更改座位，固定 seed 与发牌随机流独立于 AI 决策随机流。

回归覆盖便宜加注防守、昂贵加注撤退、对子/强听牌小注跟进、河牌空气的大注纪律、强牌价值再加、短全押不重新开放加注，以及隐藏牌/牌库/烧牌置换不影响决策。所有行动仍经过同一个下注规则校验器，牌型、主池、边池和筹码守恒规则保持一致。
