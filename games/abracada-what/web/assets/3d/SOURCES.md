# 3D asset sources

Only the runtime files used by the browser are retained from each source pack.

- `characters/mage.glb`: the pointed-hat mage base model used for all five seat-bound wizard variants; each seat adds its own color treatment and magical insignia. From KayKit Character Pack: Adventurers 2.0 Free by Kay Lousberg, CC0 1.0, downloaded from https://kaylousberg.itch.io/kaykit-adventurers
- `animations/*.glb`: KayKit Character Animations 1.1 Free by Kay Lousberg, CC0 1.0, downloaded from https://kaylousberg.itch.io/kaykit-character-animations
- `dungeon/*`: KayKit Dungeon Pack 1.1 Free by Kay Lousberg, CC0 1.0, downloaded from https://kaylousberg.itch.io/kaykit-dungeon-pack
- `particles/*.png`: Kenney Particle Pack 1.0 by Kenney, CC0 1.0, downloaded from https://kenney.nl/assets/particle-pack
