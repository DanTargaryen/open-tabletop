# 钢铁远征 / Steel Expedition

原创 2D 横版回合制坦克炮战。玩家与本地规则 AI 在 `2560 × 720` 的横向战区中轮流移动、校准角度和力度，并使用四档七种炮弹破坏对手与战场地形。单人和多人共用 `web/camera.js`：移动时近景跟随，停止移动 0.3 秒后平滑拉远到自己与最近存活敌人，调整角度和力度时保持画面稳定；炮弹接近画面边界时才跟随，落点停留约 0.9 秒后切换行动坦克。顶部战区定位条显示双方、补给与当前视口的位置。

## 操作

- `A` / `D`：移动（移动仅使用键盘）
- 鼠标在左下圆盘中向后拉：炮弹向反方向发射，可自由选择前后、上下任意方向
- 拉伸距离：控制发射力度，拉得越远力度越大
- `W` / `S`：旋转射击方向；`Q` / `E`：微调力度
- 鼠标点击弹药卡，或用 `1`—`7`：选择校准、穿甲、震地、钻地、蜂巢、核爆或追踪弹
- 鼠标点击“开火”，或用 `Space`：开火
- 鼠标点击菜单项和暂停按钮，或使用对应键盘快捷键
- `Esc`：暂停或返回
- `Enter`：确认菜单
- `R`：结算后重新开始

游戏只面向电脑浏览器。坦克移动固定使用 `A/D`，瞄准、力度、选弹、开火和菜单同时支持鼠标与键盘；不提供触摸端专门适配。规则和弹道位于 `web/engine.js`，可以在 Node 测试中直接导入。

第 1～2 回合只有无限校准弹；第 3 回合开放两种二档弹并各发 2 发；第 5 回合开放两种三档弹并各发 2 发。每 3 个行动回合投放一次补给，落点保证至少一辆坦克能在 0～2 次满燃料移动内拾取；补给有 50% 概率恢复 30 生命，另有 50% 概率随机给予一发核爆弹或追踪弹。追踪弹发射后自动锁定最近的存活敌军并保证命中；核爆弹拥有全游戏最高伤害、最大爆炸范围和最强地形破坏。

## AI 难度

单人主菜单可选择简单、普通、困难，选择会保存在当前浏览器中，下次开局生效。好友房由房主为每个 AI 座位单独选择，默认普通。两种模式调用同一个 `chooseTankAiAction`，三档通过弹道搜索精度、角度和力度误差区分，生命、燃料、弹药和伤害不加成；共用补给拾取和友军爆炸风险判断。

多人补给沿用单人的投放间隔、奖励、落点和下降函数。服务端保存每发射击后的空投初始状态，浏览器在落点停留后播放 0.95 秒下降，再开放下一次行动。

## 好友房

好友房提供 `A1`、`B1`、`A2`、`B2` 四个座位，默认不添加 AI，也不设置真人上限选项。每位真人都可以更换空座位，只有房主能在空位添加或移除 AI。支持 1 对 1、2 对 1、两名真人同队对两名 AI 等组合；双方各至少有一名真人或 AI，且所有真人准备后才可开局。只有实际参战位置生成坦克，行动按 `A1 → B1 → A2 → B2` 顺序跳过空位及已被击毁的位置。

服务端权威保存共享地形、坦克生命、燃料、弹药和补给，并结算移动、弹道、爆炸与地形破坏。打开页面先显示创建/加入，当前标签页的身份可通过“重新连接原房间”恢复，邀请链接不会自动进入其他旧房。房主离开时权限交给剩余真人；战斗中离席或 90 秒未行动时由 AI 代打。Node 使用私有数据文件 `steel-arc-rooms.json`，Cloudflare Worker 使用迁移 `0006_steel_arc_rooms.sql`。

## 验证

规则与服务测试运行 `npm test`，静态资源检查运行 `npm run build:static`。
浏览器回归需要本地安装 Playwright（`npm install --no-save --package-lock=false playwright`）和 Microsoft Edge，然后运行 `npm run test:e2e:steel` 与 `npm run test:audio:steel`。也可将 `PLAYWRIGHT_MODULE_PATH` 设为已有 Playwright 安装目录中的 `package.json` 绝对路径。测试截图与临时房间数据输出到已忽略的 `_qa/`，不应提交。

## 音频

单人和多人共用 `web/audio.js`。背景音乐随战斗循环播放，七种炮弹分别使用本地录音素材，发射与命中调整播放音高和音量；声音开关同时控制音乐与音效。当前为复用项目已下载音频的临时选曲，来源、作者、许可和原文件名见 [音频来源](web/assets/audio/SOURCES.md)。本次联网筛选新素材因网络审批服务故障尚未完成。

## 美术资产

单人和多人共同使用 `web/renderer.js` 绘制坦克、炮弹、爆炸、地形断面和战场装饰。多人射击回放使用服务端提供的射击前状态，并调用同一个 `web/engine.js` 计算弹道、分裂与地形破坏。Canvas 会依据窗口与设备像素比提高实际输出分辨率，最高使用 3 倍采样。部件名称、世界尺寸与材质色表见 [`ART_ASSETS.md`](./ART_ASSETS.md)。
