# 丝绒牌局 · Texas Hold'em

Open Tabletop 的第一款游戏：六席无限注德州扑克，支持单人 AI 练习和 1–6 位真人好友房，空位由 AI 补齐。只有虚拟筹码，没有支付功能。

只有你一个人在好友房时，点“一个人开局”即可与 5 位 AI 对战。有人加入后，仍需所有真人在线并准备。单人完成一手后，自己准备即可进入下一手。

在仓库根目录运行 `npm start`，通过合集首页进入游戏。单人进度留在当前浏览器；联机状态保存在服务器，刷新后凭同一浏览器内的座位身份恢复。不要分享个人重连身份，只分享房间邀请链接。

- 轻松练习每手恢复 2,000 筹码，盲注固定 10 / 20。
- 单桌锦标赛保留筹码，每 10 手升盲，直到剩下最后一位。
- 结算时，各座位显示本手公开的牌型和赢家所得；弃牌、未摊牌、未参与分别标注。
- 当前牌桌每秒检查；等候室/结算约 2 秒、后台页面约 5 秒；没变化时省略牌桌及历史正文。
- 45 秒内未行动，服务器自动过牌或弃牌。所有玩家在后台时，AI 和超时推进可能等到下一次轮询。
- 房间在最近活动后保留 24 小时；历史窗口为最近 12 手。

## AI 牌友打法

这些是游戏中的虚构性格，不是对应模型供应商的真实行为。每位 AI 只使用自己的底牌、公共牌和公开行动；角色短句不会透露额外牌面信息。

| 角色 | 偏好 |
| --- | --- |
| 豆包 · 宽松跟进 | 更愿意入池看翻牌和跟小注，有优势时也主动下注。 |
| ChatGPT · 位置进攻 | 利用后位偷盲、翻牌后延续进攻，选择少量轻型再加注。 |
| Claude · 精选强攻 | 起手牌仍较精选，但强牌更主动，价值下注尺度更大。 |
| GLM · 主动施压 | 入池范围更宽，主动下注和加注更频繁。 |
| DeepSeek · 埋伏反击 | 同花或顺子听牌会半诈唬，强牌有时过牌埋伏再反击。 |

头像悬停可查看简短策略说明。诈唬受每街次数和筹码预算限制；不会因为最小加注太大，把普通诈唬升级成深筹码全押。策略仍是启发式与随机权益采样，不是 GTO 解算器。

行为对比与测量方法见 [AI 策略说明](../../docs/ai-strategies.md)。在仓库根目录运行 `node games/texas-holdem/scripts/measure-ai.mjs --hands 250 --difficulty standard` 可以重复当前策略的行为测量。

## 文件

- `web/engine.js`：规则、牌型评估与本地 AI。
- `web/ui.js`、`web/online-ui.js`：单人和好友房界面。
- `web/room-sync.js`：按座位隔离的轻量状态缓存。
- `server/rooms.mjs`：服务器掌握完整牌局，返回各座位允许看到的信息。
- `server/api.mjs`：HTTP API 和可选 D1 存储适配。
- `server/migrations/`：可选 Cloudflare D1 初始迁移。
- `tests/`：引擎、房间和同步回归测试。

运行 `npm test` 验证整个合集；运行 `npm run measure:poker-sync` 在本地比较新旧同步的响应正文大小。压缩对比不等于实际网络账单或平台额度。
