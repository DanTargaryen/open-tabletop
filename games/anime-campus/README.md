# 放学后，掷个六！

六作品混搭的非官方校园祭冒险棋。60 格固定地图包含 52 个事件格、51 种不同事件、6 个休息点、安全格与终点。可选美琴、薰、辉夜、大河、薇尔莉特、六花，使用六种基础道具。

- `/games/anime-campus/index.html`：1 人＋AI、2–4 人同屏、AI 演示；本地存档、地图缩放、跳过动画与音效开关。
- `/games/anime-campus/online.html`：1–4 人好友房、AI 补位、准备、刷新恢复、45 秒超时代行。
- `npm start` 启动合集；公网旧版本不会因本地修改自动更新。

规则来自本次原创主题方案。首版没有单独装备工具箱和乐谱夹，对应两个格子统一提示使用应援券防御。试玩修订：设备过热 R07 与接驳停运 X11 均损失 1 心情并令下次移动减 1；一次防御可取消整组处罚，R07 的 1 零花钱补偿不受防御影响；心情归零则立即中止当前事件的剩余效果。这样回血与复活在固定地图上有实际用途。`web/data.js` 记录固定地图及卡面，`web/engine.js` 由本地 UI 与服务端共用。骰点为独立公平 D6，移动修正另行计算；事件位移不连锁触发落格。正常前进经过 9、17、25、33、41、49 即签到；直接换位落在新休息点也应签到。事件结算后到达 60 且心情大于 0 获胜，30 完整轮后依位置、心情、零花钱结算。

角色技能每局一次；主动道具与主动技能共用回合额度，防御与移动前重掷另有时机。官方头像是可选的本地素材包：

```sh
node games/anime-campus/scripts/install-official-art.mjs
```

安装器从已记录的官方来源下载并校验 SHA-256，保留原始图片字节，只以 SVG 取景。素材安装在 Git 忽略的 `web/assets/official/`，不会被当作 MIT 素材提交。缺少时客户端使用通用头像。见 [素材来源](SOURCES.md)。

## 联机与存储

`/api/anime-campus` 使用独立 Node 文件 `anime-campus-rooms.json`。服务器生成骰点、校验行动，版本 CAS 与 requestId 防止旧状态和重复结算。身份凭证仅返回本人，服务端存摘要；同时选择与记忆答案按视角隐藏。明确离开撤销身份并由 AI 接手。

房间活动 TTL 为 24 小时。AI 与超时由有身份的轮询请求推动，每次最多一步；没有在线请求时不会自行推进。好友房身份保存在标签页 sessionStorage，刷新和同标签页返回可恢复，关闭标签页后不保证继续恢复原座位。

可选 Cloudflare Worker 路由与 `0005_anime_campus_rooms.sql` 使用独立房间及限流表。迁移与适配器通过本地测试不等于已经部署上线。
