# 来源与素材范围

玩法、回合处理、地图路径、矢量地标、道具图标与合成音效由本项目实现；本作是非官方作品混搭，不表示相关创作者参与或背书。

六个角色的名称与设定线索参考各自官方网站：

- [御坂美琴](https://toaru-project.com/railgun_t/chara/mikoto.html)
- [宫园薰](https://www.kimiuso.jp/character/)
- [四宫辉夜](https://kaguya.love/character/)
- [逢坂大河](https://www.tv-tokyo.co.jp/contents/toradora/chara/)
- [薇尔莉特](https://tv.violet-evergarden.jp/character/)
- [小鸟游六花](https://www.anime-chu-2.com/tv/character/rikka/)

`assets-sources.json` 记录官方原图地址、校验和、尺寸与取景框；不声明这些原图具有开放许可。真实原画仅在本地可选素材目录 `web/assets/official/` 安装，目录被 Git 忽略。项目 MIT 许可不授予动漫角色图像的权利。公开发行素材须按仓库的分发要求另行处理。

校园祭、跨作品相遇和游戏事件为原创设计；红心棋盘、魔法阵装饰和小物件不是官方授权素材或原作场景复刻。
