# 规则与素材来源

核对日期：2026-09-13。飞行棋有不同地区、厂商和家庭规则，本实现不宣称唯一官方规则。

## 规则参考

- [游戏茶苑：飞行棋的规则](https://www.gametea.com/ask/201701/4765.html)：游戏运营方对起飞、续掷、跳格与虚线飞越的说明。
- [App Store：飞行棋人机大作战](https://apps.apple.com/cn/app/id1115245319)：开发者提供的起飞、飞越、终点反弹说明；该版本叠机含路障，本合集不采用路障。
- [Big Fish Workshop：飞行棋基本玩法](https://ivankei.wixsite.com/bigfishworkshop/fei1hang4kei4)：说明独立 / 共同叠机应先约定、直接飞越和跳入飞越的差别，以及交叉点撞机。本合集不采用该说明中的三连六惩罚。

规则按独立代码重新实现，未复制上述页面的代码、美术或完整规则文案。固定选择详见 README 与游戏内帮助；各模式共用一套规则。

## 视觉与声音

- 棋盘、飞机按钮、骰子、快捷航线与界面由本项目原创 SVG / HTML / CSS 绘制，沿用仓库 MIT 许可。
- `web/assets/airplane-club.jpg`：为本项目用 OpenAI Image Gen 生成的原创玩具飞机插画，经本地缩放与 JPEG 编码用于大厅；不是原版棋盘扫描件或第三方产品图。画面无外部品牌标识。
- 音效由 `web/audio.js` 通过 Web Audio 振荡器现场合成，无第三方采样、远程请求或音频包。
- 页面使用系统字体，无外部字体服务或新增运行依赖。
