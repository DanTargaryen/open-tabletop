## 后续三维制作注意事项

- 按轮廓和主要配色建模；图中的微小磨损、倒角可以进一步省略。
- 香烟、药瓶盖、药片和注射器活塞等需要操作的零件应拆为独立子件。
- 放大镜镜片与注射器针筒需要真正的透明材质。
- 手机依靠按键屏幕与其他道具区分。
- 图中展示尺寸不代表游戏内相对尺寸；制作时按手掌、桌面槽位统一缩放。
- 图片不能验证网格面数、背面结构或绑定，制作三维资产时另行检查。
