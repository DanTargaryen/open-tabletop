# 恶魔轮盘：八种道具的功能与交互动画

日期：2026-09-16  
依据：`buckshot-roulette-items.md` 的规则；本文只写**实现时必须遵守的功能和动画**。  
角色：玩家与庄家都是骷髅。**右手拿枪，左手拿道具**。玩家是第一人称，闲置时看不见自己的手臂，只有做动作时才伸出骨臂。

道具用了什么、结果是什么，**都靠动画交代**。不要道具读屏，不要往信息区写弹药。不能用时仍要当场说明原因（点了没反应会以为卡死）。

## 0. 当前完成度（写本文时）

| 层 | 状态 |
| --- | --- |
| 引擎功能 | 八种道具的效果、限制、AI 决策、容量 8、开局 4 件都已写进 `engine.js` |
| 桌面操作 | 点自己的道具即用。肾上腺素仍是先选目标再结算，**实现时改成先扎再选** |
| 动画 | 只有放大镜有专用分镜，而且用弹膛灯，**实现时改成拉栓露弹**。其余道具还没有按种类做完 |
| 已知 bug | 左手拿道具时会把格子盖板一起带走。拿的时候**只拿物件，盖板留在桌上** |

接下来按本文把每种道具的动画补齐。功能以引擎为准，动画**不得重新掷随机、不得改行动权**。除肾上腺素外：引擎先结算，把同一份结果交给动画播放。肾上腺素见第 7 节。

## 1. 所有道具共用的规矩

### 1.1 行动权

使用任一道具都不交出行动权。用完可以继续用别的道具，或点枪射击。生命降到 0 立即结束，不再播后续动作。

### 1.2 谁的手

| 动作 | 手 |
| --- | --- |
| 拿枪、举枪、拉栓、瞄准、放回枪 | 右手 |
| 拿桌上的道具、使用、放回 | 左手 |
| 放大镜看弹药 | 左手拿镜，右手把枪端起来并拉栓拉一半 |
| 肾上腺素 | 左手拿针筒扎自己，再伸向对手那一件 |

庄家两只手臂平时垂在桌下两侧，动作时抬上桌。玩家两只手臂平时隐藏，动作开始时出现，收手后立刻藏掉。被手铐铐住时例外：两只手必须一直放在桌上，见第 5 节。

### 1.3 点击

- 只有轮到自己、没在播动画、没被手铐跳过时，才能点。
- 能用的道具轻微抬高，点下去就用，不再弹确认框。
- 不能用的道具点了要说出原因，不消耗、不播使用动画。
- 肾上腺素：点下去就扎自己，扎完再选对手的道具。扎完不能取消。

### 1.4 公开和私有

公开（双方都能从桌面看懂）：用了哪一种道具、啤酒退出的是实弹还是空弹、过期药物回血还是扣血、手铐铐了谁、枪管是否锯短。

私有（只有使用者自己能看清）：放大镜拉栓后弹膛里那半颗的颜色、手机屏幕上的字。庄家用这两件时，不要把弹膛或屏幕怼到玩家能读的角度。

### 1.5 拿起、放回、翻转

所有道具共用这一套，不要再淡出消失。

1. 左手伸向桌上的物件，**只抓住道具本身**。盖板、凹槽、白线格子全部留在原位，不要连板子一起拎起来。
2. 做完这件道具自己的使用动作。
3. 左手把物件放回**原来那一格**，松手。
4. 这一格的盖板带着已经放回去的道具，一起翻转下去。格子空着，其余格不动。
5. 左手收回。

被肾上腺素偷走的那一件：用完后放回**对手原来那一格**，再翻下去。

### 1.6 节奏

普通道具：拿起 0.3 秒 → 使用 0.5～0.8 秒 → 放回并翻转 0.4 秒，合计大约 1.2～1.5 秒。  
放大镜、手锯、肾上腺素：合计大约 1.5～2.5 秒。肾上腺素还要等玩家选目标，选目标的时间不计入这段。  
遵守 `prefers-reduced-motion` 时把每段压到 90 毫秒以内，但状态变化（生命、弹数、已知弹药、铐住姿势）必须立刻到位。

### 1.7 失败不能卡死

动画中途报错也要放开输入锁，已经结算的结果必须留在画面上。不能出现“横幅写着轮到你，但什么都点不了”。

## 2. 放大镜 `magnifier`

### 功能

查看**当前这颗**弹药是实弹还是空弹。不射击、不退弹、不改顺序。

结果写进使用者的弹药笔记。这颗被打掉或被啤酒退出后，笔记删掉。

### 不能用

| 原因 | 提示 |
| --- | --- |
| 弹仓空 | 弹仓为空 |
| 自己已经知道当前这颗 | 已知当前弹药 |

### 玩家怎么点

点自己桌上的放大镜。立刻消耗，立刻结算。

### 画面结果

不要亮灯，不要往信息区写「下一发：实弹／空弹」。

玩家使用：右手把枪的前托**只拉到一半**，弹膛里露出当前这颗的**一半**，颜色能看清（实弹红、空弹蓝）。颜色必须和引擎结算的当前弹药一致。看完把栓推回去，半颗子弹收回去。

庄家使用：庄家自己低头看这一半。玩家镜头不要给弹膛特写，玩家不能靠颜色读出结果。

### 动画分镜

1. 左手拿起放大镜（不带盖板）。
2. 右手同时抓住枪托，把枪抬到身前。
3. 右手把前托向后拉到大约一半行程，停住。弹膛里滑出半颗弹药，颜色朝向使用者。
4. 左手把镜片凑到这半颗上方，停大约 0.4 秒。
5. 右手把前托推回原位，半颗弹药收回枪内。不要拉到底，不要开火，不要把这颗退出去。
6. 左手把放大镜放回原格，盖板带着它翻转下去。右手把枪放回桌心。双手收回。

## 3. 香烟 `cigarette`

### 功能

恢复 1 点生命，不超过上限 3。一件烟盒只用一次。

### 不能用

满血。提示「生命值已满」。不消耗。

### 玩家怎么点

点自己桌上的烟盒。

### 画面结果

对应一侧的电荷显示器多一格闪电。不要读屏。

### 动画分镜

1. 左手拿起烟盒（不带盖板）。
2. 从盒里抽出一根烟（可用模型上已有的那根烟），送到头骨齿间。
3. 烟头短暂发红，冒一小缕烟（透明、不挡桌面）。
4. 生命显示器跳到新值。
5. 左手把烟盒放回原格，盖板带着它翻转下去。左手收回。

右手全程不动、不碰枪。

## 4. 啤酒 `beer`

### 功能

退出当前弹药，不造成伤害。双方都看到退出的是实弹还是空弹。

若这是弹仓里最后一颗：立刻重新装填（新弹数、新实弹/空弹比、补道具），**仍由使用者行动**。啤酒本身不消耗手锯状态；但若因此触发装填，装填会清掉手锯。

### 不能用

弹仓为空。提示「弹仓为空」。

### 玩家怎么点

点自己桌上的啤酒罐。

### 画面结果

不要读屏。退出的那颗完整弹药（红实弹或蓝空弹）双方都看得见。弹药陈列按规则翻对应格子：实弹翻最左红格，空弹翻最右蓝格。若跨轮，播装填动画。

### 动画分镜

1. 左手拿起易拉罐（不带盖板），送到头骨前做短促的喝一口。
2. 右手抓住枪。泵动前托**后拉再推回**（退弹，**不是开火，也不是放大镜那种只拉一半**）：无火光、无枪口灯。
3. 一颗完整弹药（与结算结果一致）从枪口或抛壳口落到桌面，短暂停留后消失或滚出画面。同时弹药陈列翻掉对应那一格。
4. 左手把易拉罐放回原格，盖板带着它翻转下去。枪放回。双手收回。

禁止拿啤酒动画当射击用。空包弹退弹和实弹退弹都没有火光。

## 5. 手铐 `cuffs`

### 功能

给对手加一次束缚。下一次轮到对手时，跳过他的整回合，行动权回到自己。

同一段连续行动里只能成功铐一次。对手已被铐住时不能再铐。对手被跳过后如果自己还继续行动，也不能立刻再铐。

### 不能用

| 原因 | 提示 |
| --- | --- |
| 对手已经被铐 | 对手已经被手铐束缚 |
| 这段行动已经用过手铐 | 本段行动已经用过手铐 |

### 玩家怎么点

点自己桌上的手铐。立刻铐向庄家。

### 画面结果

不要读屏。被铐住的人进入**保持动作**，直到手铐效果解除。

束缚真正触发、跳过那一回合时：铐打开或从手腕上取下，双手收回，保持动作结束。不要只靠横幅交代。

### 动画分镜

1. 左手拿起手铐（不带盖板）。
2. 朝对手一侧手腕方向递出（玩家铐庄家：往桌对面伸；庄家铐玩家：往镜头近处伸）。
3. 对手**两只手放到桌上**，铐环扣在双手腕上，能一眼看出被铐住。
4. 左手把用过的手铐放回原格，盖板带着它翻转下去。左手收回。
5. **保持**：被铐的人两只手一直放在桌上、腕上有铐，直到效果解除。庄家被铐：两只骨臂撑在对面桌沿。玩家被铐：第一人称两只骨臂出现在近处桌沿，不能藏起来。
6. 效果解除（跳过他的回合之后）：铐从手腕上离开，双手收回。玩家被解除后骨臂再藏掉。

保持期间被铐的人不能做别的手部动作。铐人的那一方仍可正常行动。

## 6. 锯子 `saw`

### 功能

使用者下一次射击中，实弹伤害变成 2，空弹仍是 0。无论打谁、无论实弹空弹，这一枪之后增伤消失。不叠加。

### 不能用

已经锯短。提示「枪管已经锯短」。

### 玩家怎么点

点自己桌上的锯子。

### 画面结果

不要读屏。枪在桌上变成短管外观（或前段收进去），直到打出下一枪。不要只靠状态文字。

### 动画分镜

1. 左手拿起锯子（不带盖板）。
2. 右手把枪稳住在桌上（不必完全举起）。
3. 左手在枪管中段来回锯两下。枪管换成短管外观。
4. 左手把锯子放回原格，盖板带着它翻转下去。双手收回。

打出下一枪时：按短管播射击；放回桌上后恢复长管。不要求模拟永久砍坏。装填也会恢复长管。

## 7. 肾上腺素 `adrenaline`

### 功能

选择对手的一件**此刻对自己合法**的道具，偷来并立刻以自己的身份使用。偷来的东西不进自己的库存。自己满 8 件也能用。

不能偷另一支肾上腺素。不能偷自己当前用不了的道具（满血不能偷香烟或过期药物，已有锯子不能偷锯子，弹仓一发不能偷手机，等等）。

### 不能用

对手没有可偷的合法道具。提示「对手没有可偷的道具」。点下去之前就要拦住，不能先扎再发现没得偷。

选目标过程中局面变了（例如对手那件已经不能用）：确认时再校验，失败则提示「这件道具现在偷不了」，**针筒已经用掉**，留在选目标，直到点到一件合法的。

### 玩家怎么点

1. 点自己桌上的肾上腺素。若不能用，只提示原因，什么都不播。
2. 能用：立刻拿起并**扎进自己**（锁骨或前臂均可，动作必须清楚）。扎完针筒消耗，放回自己那一格翻转下去。
3. 进入选目标。对手桌上可偷的那几件抬高。**不能 Esc 取消**——已经扎过了。
4. 点对手一件合法道具：结算那一件的效果，再按那一件自己的分镜播放（使用者是偷的人）。
5. 点到不合法的：提示「这件道具现在偷不了」，继续等。

庄家使用时由 AI 选目标，但动画仍是：**先扎自己，再去拿被偷的那一件**。玩家不能中途取消。

### 画面结果

不要读屏。扎自己必须看到。随后被偷道具按它自己的公开/私有规则表演（偷到啤酒能看见退出实弹还是空弹；偷到放大镜或手机，私有结果只给偷的人看清）。

### 动画分镜

**先扎再选。** 点下去就要播注射，不要等选完目标才扎。

1. 左手拿起自己的注射器（不带盖板）。
2. 对着自己做一次清楚的注射（针尖进锁骨或前臂，停大约 0.3 秒）。
3. 左手把空针筒放回自己原格，盖板带着它翻转下去。
4. **此时才进入选目标**（庄家则立刻伸向 AI 已选好的那一件）。
5. 左手伸向对手桌上被选中的那一件，只拿物件、不带盖板。
6. **接着播放被偷道具自己的使用动画**（偷到香烟就吸烟回血，偷到放大镜就按放大镜分镜拉栓露弹）。这一段的使用者是偷的人，不是原主人。
7. 用完后把那一件放回**对手原来那一格**，盖板带着它翻转下去。收手。

总时长允许到约 2.5 秒（不含玩家选目标的等待）。两段动画不要重叠抢同一只左手。针筒和被偷道具不要同时抓在手里。

结算时机：扎自己结束时消耗肾上腺素；点中目标后才结算被偷道具的效果。动画不能在选目标之前把对方的物件翻掉。

## 8. 过期药物 `expiredMedicine`

### 功能

使用时只随机一次：50% 恢复 2 点生命（仍受上限 3 限制），50% 失去 1 点生命。扣到 0 立即判负。

随机由引擎在结算时抽好，动画只能表演 `good` 和 `delta`，不能再抽一次。

### 不能用

满血。提示「生命值已满」。  
当前 1 点生命时**允许使用**，但点下去之前应让玩家知道失败会失去最后 1 点（可用横幅或按钮说明「失败会失去最后 1 点生命」）。

### 玩家怎么点

点自己桌上的药瓶。

### 画面结果

不要读屏。电荷显示器立刻变成新值。成功短暂绿色回闪，失败短暂红色闪一下（比中弹轻）。若因此死亡，进入终局，不再让庄家行动。

### 动画分镜

1. 左手拿起药瓶（不带盖板），瓶盖已在模型旁可一并带起。
2. 倒出药片送到头骨处服下。
3. 停约 0.25 秒。
4. 成功或失败按上面的画面结果表演。
5. 左手把药瓶放回原格，盖板带着它翻转下去。左手收回。

不举枪。

## 9. 一次性手机 `burnerPhone`

### 功能

在当前弹仓**第 2 发到最后一发**里，优先从未被自己知道的弹药中等概率挑一颗，告诉使用者它的位置和类型，例如「第 4 发是实弹」。不消耗弹药、不改顺序。

前面的弹药被打掉或退出后，记录跟着前移：原来的「第 4 发」会变成「第 3 发」，直到变成「下一发」或被消耗后删除。重新装填清空全部手机记录。

### 不能用

| 原因 | 提示 |
| --- | --- |
| 只剩 0 或 1 发 | 后续弹药不足 |
| 第 2 发及以后自己都已经知道 | 后续弹药均已知 |

### 玩家怎么点

点自己桌上的手机。

### 画面结果

不要读屏，不要写进信息区。结果只出现在**这台手机的屏幕上**，格式固定为：

「第 N 发子弹是实弹」或「第 N 发子弹是空弹」

字要能看清。N 和实弹/空弹必须与引擎结算一致。

玩家使用：屏幕朝向玩家。  
庄家使用：屏幕朝向庄家，玩家读不到字。

### 动画分镜

1. 左手拿起手机（不带盖板），举到使用者面前（玩家：靠近镜头；庄家：靠近头骨）。
2. 屏幕亮起，写出「第 N 发子弹是实弹／空弹」，停大约 0.8 秒。
3. 屏幕暗掉。左手把手机放回原格，盖板带着它翻转下去。左手收回。

不举枪。不要把庄家手机上的字给玩家看。

## 10. 和枪、生命、弹药陈列的配合

格子、翻转方向和“公开数量 ≠ 弹仓顺序”写在 `buckshot-roulette-table-slots.md`。道具使用动画不要和那一套抢同一物件。拿道具时不要把盖板从那一套里拽走。

| 事件 | 桌面必须同步 |
| --- | --- |
| 香烟 / 过期药物改变生命 | 对应一侧电荷机闪电格数 |
| 啤酒退弹、射击 | 实弹翻最左红格，空弹翻最右蓝格；格子空着，不重排、不泄露顺序 |
| 使用 / 被偷走道具 | 用完放回原格，盖板带着物件翻下去，其余格不动 |
| 放大镜 | 拉栓一半露出半颗当前弹药；看完推回。不要灯，不要信息区 |
| 手机 | 屏幕写「第 N 发子弹是实弹／空弹」。不要信息区 |
| 锯子开 / 关 | 短管外观，直到打出下一枪或装填 |
| 手铐开 / 关 | 被铐者双手放桌上、腕上有铐，直到效果解除 |
| 装填 | 旧弹已全部朝下后，新弹按左红右蓝翻上来；空道具格里新件翻上来；放大镜半露的弹药收回；锯子恢复长管 |

射击本身不是道具，但和锯子、手铐绑在一起：右手举枪 → 瞄准「庄家」或「自己」→ 实弹有火光，空弹没有 → 拉栓 → 放回。道具动画不要插入这套射击流程中间。放大镜的「拉一半」不是射击拉栓，不要共用同一套播完即推回的全程。

## 11. 建议实现顺序

引擎功能已经能跑通。按动画从简到繁做，每做完一种就实际点一次玩家侧、看一次庄家侧。

1. **拿放翻转**：修好「只拿物件、不带盖板」；用完放回原格再翻下去。所有道具都依赖这一步。
2. **香烟**：左手吸烟 + 生命加一格 + 放回翻转。
3. **过期药物**：同香烟骨架，分支成功/失败/致死。
4. **手铐**：铐上之后进入双手放桌的保持，跳过回合后再解开。
5. **锯子**：左手锯管 + 短管状态，打一枪验证恢复。
6. **放大镜**：拉栓一半露半颗；玩家能看清颜色，庄家用时玩家看不清。
7. **啤酒**：喝一口 + 右手退弹（拉到底、无火光）+ 弹药落地；再测退掉最后一发仍轮到自己。
8. **手机**：举到面前，屏幕写「第 N 发子弹是实弹／空弹」；庄家使用时玩家读不到。
9. **肾上腺素**：先扎自己并翻掉针筒 → 再选目标 → 接被偷道具的完整动画。

做完第 9 项后，用「放大镜 + 锯子 + 射击」「手铐后自射空弹再交权」「肾上腺素偷香烟」三条组合过一遍，确认没有动画抢手、没有把盖板拎走、没有锁死输入、没有把庄家的弹药信息漏给玩家。
