# 恶魔轮盘：桌面格子、弹药陈列与翻转

日期：2026-09-16  
本文只写桌面上**看得见的格子和翻转**。不改引擎规则，也不在这一步做道具使用动画。  
弹药顺序仍然只存在引擎弹仓里；桌上这一排永远只公开**还剩几发实弹、几发空弹**。

## 0. 为什么要改

现在的弹药区是一条长框，子弹挤在框里，看起来像 HUD，不像桌面物件。原作是毡面上画好的白线格子，物件坐进格子里。

差距主要不在“像不像原作贴图”，而在三件事：

1. 格子是一条大框，不是一发一格。
2. 子弹没有坐进格子，间距也不是格子宽度。
3. 消耗时整排重建或凭空消失，没有“这格用掉了”的交代。

道具区已经有每人两排四格，但线和物件的关系同样偏松。弹药和道具改成同一套语言：**用掉翻下去，刷新翻上来**。

## 1. 公开陈列 ≠ 弹仓顺序

弹仓是有顺序的队列，射击和啤酒永远消耗最前面那一发。  
桌上这一排**禁止**按真实顺序摆。永远是：

- 红色实弹从**左边**往右排
- 蓝色空弹从**右边**往左排
- 中间空着的格子就是还没占满的容量

例如本轮 4 实弹 1 空弹、容量 8 格：

```
[红][红][红][红][  ][  ][  ][蓝]
```

再打出一发实弹，不论它在弹仓里是第几发，桌上只把**最左边那颗还朝上的红弹**翻下去：

```
[翻][红][红][红][  ][  ][  ][蓝]
```

再退出一发空弹，只把**最右边那颗还朝上的蓝弹**翻下去：

```
[翻][红][红][红][  ][  ][  ][翻]
```

玩家由此只读出“实弹少了一发 / 空弹少了一发”，读不出下一发是什么。

## 2. 弹药格

### 2.1 画在桌上

- 枪的右侧画 **8 个连在一起的格子**，不是一条大长框。
- **一格的内框刚好装下一发子弹**：子弹躺进格子后，四周留很窄的白线边，不能左右挤两发，也不能一发明显小于格子。
- 格子是毡面上的白漆线，细、直角、连成一条托盘。不要写 `CHAMBER LOADOUT` 这种界面字。
- 本轮装不满 8 发时，空格仍然画着，只是没有子弹。

建议尺寸（桌面单位，实现时可微调，但必须“一发一格”）：

| 量 | 值 |
| --- | --- |
| 弹药格数量 | 8 |
| 格内宽 × 深 | 约 `0.10 × 0.16`（短边沿枪身方向，长边沿桌深，让弹壳能平躺） |
| 格与格的缝 | 共线，不要再额外拉开间距 |
| 子弹模型 | 平躺在格底，黄铜底朝向玩家或统一朝同一侧 |

### 2.2 装填时怎么占格

设本轮实弹 `L`、空弹 `B`，`L + B ≤ 8`。

- 实弹占第 `0 .. L-1` 格（最左开始）
- 空弹占第 `8-B .. 7` 格（最右开始）
- 其余格空着

新一轮开始：先清掉上一轮已经翻下去的弹，再按新的 `L`、`B` 把新弹从格子里**翻转上来**。不要从天上掉下来，也不要突然出现。

### 2.3 什么时候翻下去

| 事件 | 翻哪一颗 |
| --- | --- |
| 射击实弹 | 最左边还朝上的红弹 |
| 射击空弹 | 最右边还朝上的蓝弹 |
| 啤酒退出实弹 | 同射击实弹 |
| 啤酒退出空弹 | 同射击空弹 |

放大镜、手机、锯子、手铐**不**动弹药格。

翻的方式：子弹绕短轴转到格底里，背面朝上或没入毡面，这一格重新露出白线空位。已经翻下去的弹不要再挪到别的格子，也不要把剩下的弹重新挤到一起。

### 2.4 一轮打完

一轮里每一发被打出或退出时都已经翻过。弹仓空了的时候，桌上朝上的弹应该一颗都不剩。

然后才装填下一轮：空格里按新的左右规则把新弹翻上来。  
若啤酒退出最后一发并立刻装填：先完成“最后一发翻下去”，再播“新弹翻上来”，中间不要闪成空桌再闪出新弹。

对局结束（有人生命到 0）则停住，剩下没翻的弹保持朝上，不再刷新。

## 3. 道具格

### 3.1 画在桌上

和原作一样：自己一侧、庄家一侧各 **两排四格，共 8 格**，白漆线连成一块，不是八个互不相干的小方块。

- 一格刚好坐下当前道具模型（模型还要改的话，以格子为准去收模型，不要为了模型去撑格子）。
- 靠自己的那一排先放，放满再放到远的那一排。
- 空格始终画着。库存不满 8 件时，多出来的是空格，不是没有线。

玩家道具在近侧，庄家道具在远侧。双方道具都公开摆在桌上。

### 3.2 用掉：翻下去

点中并成功使用某一件（或被肾上腺素偷走）时：

1. 只翻**那一格**里的那一件，其它格不动。
2. 翻下去后这格变空，引擎已经从库存里删掉它，新道具以后可以占这格。
3. 不要把剩下的道具往前挤。玩家认的是“哪一格那一件”，肾上腺素偷的也是槽位。

失败或不能用：格子和模型都不动。

### 3.3 刷新：翻上来

`loadRound` 给双方补道具时：

- 已经在桌上、还没用的道具留在原格，不要重排。
- 新抽到的道具进**最靠前的空格**，从格子里翻转上来。
- 上一轮翻下去的残件如果还看得见，在新件翻上来之前先清掉。

开局第一轮也用翻上来，不要直接摆好。若实现时第一帧就要能玩，至少不要整桌瞬变。

## 4. 和现有系统怎么接

引擎继续只提供数量：`ammoCount`、`liveCount`、双方 `items` 列表。  
桌面自己记 8 个弹药格和两侧各 8 个道具格的朝上/朝下。

同步规则：

- 朝上的红弹数 = `liveCount`
- 朝上的蓝弹数 = `ammoCount - liveCount`
- 朝上的道具 = 当前库存，槽位与 `items[side][index]` 一致

动画只表演引擎已经算完的结果。不能因为翻错格子而少扣一发或用错道具。

`prefers-reduced-motion`：翻转动画压到极短，但朝上/朝下的最终状态必须立刻正确。

## 5. 现在不要做的

- 先不要改道具使用动画（拿镜、吸烟、锯管那些）。
- 先不要为了好看去改弹仓规则或公开顺序。
- 建模仍按参考图收：子弹要能平躺进一格，道具要能坐进一格。格子尺寸定了之后，模型按格子收，而不是反过来。

实现时建议顺序：先重画毡面格子并让子弹/道具坐下 → 再做消耗翻下去 → 最后做装填翻上来。
