# 《暗膛协议》补偿机制与补偿道具设计

版本：首发设计稿\
日期：2026-09-18\
状态：已接入双人模式与单人调试陈列；本文为动画与规则验收基准

## 1. 设计目的

补偿机制不是普通的随机送道具，而是一段插入在新旧回合之间的短暂翻盘窗口。

当一方明显落后，且接下来仍由优势方掌握正常行动权时，桌面左侧升起两个独立的补偿陷阱框。弱势方从中选择一件补偿道具并立即使用，然后游戏才继续装填下一轮子弹、补发普通道具并恢复正常行动。

补偿机制应满足以下体验目标：

- 弱势方获得一次有分量的局势修正，但不凭空多获得一次开枪机会。
- 优势方能看见补偿过程和公开结果，不能操作弱势方的补偿道具。
- 补偿道具具有强烈的桌面表现、规则变化和戏剧性，不进入普通道具库存。
- 所有判定由同一份权威游戏状态完成，单人、AI 和多人模式遵守同一套核心规则。

## 2. 术语

为避免“回合”和“行动权”混淆，本文采用以下定义：

- **昼夜回合（简称回合）**：从一批新子弹装入开始，到该批子弹全部射出或退出为止。常规模式中仍按每批弹仓计算一个回合；挑战模式中，一个白天或一个黑夜对应一个回合。
- **正常行动权**：允许当前一方使用普通道具和拿枪射击的权利。
- **补偿操作权**：只允许弱势方在两个补偿道具中选择一个并立即使用。它不是正常行动权，不能借此使用普通道具或开枪。
- **弱势方**：回合结束时当前生命值较少的一方。
- **优势方**：回合结束时当前生命值较多的一方。
- **待定行动者**：完成死亡、手铐跳过等结算后，下一回合本应获得正常行动权的一方。

## 3. 触发条件

一个昼夜回合结束时，依次检查：

1. 结算最后一颗子弹、退弹及其全部伤害。
2. 检查双方是否死亡；只要对局已经结束，立即进入终局，不触发补偿。
3. 结算手铐造成的跳过，确定真正的待定行动者。
4. 比较双方当前生命值。
5. 同时满足以下条件时触发补偿：
   - 双方仍然存活；
   - 双方当前生命值相差至少 2 点；
   - 待定行动者是优势方；
   - 当前没有另一段未完成的补偿结算；
   - 当前未处于“随机死亡模式”。

如果下一回合本来就由弱势方正常行动，则不触发补偿。补偿的用途是打断“优势方领先至少 2 点且仍继续先手”的局面，而不是在每次生命差出现时固定发奖。

首版不额外设置补偿冷却：每个回合结束时都按上述条件重新判断。实际试玩若出现触发过密，再单独加入冷却，不在首版规则中预埋隐形限制。

## 4. 手铐与补偿的公平结算

手铐只剥夺正常行动权，不剥夺补偿操作权。

### 4.1 弱势方被铐住

如果回合结束后原本应轮到弱势方，但弱势方处于手铐束缚状态，则：

1. 手铐正常触发，弱势方的正常行动被跳过。
2. 该副手铐立即消耗并解除。
3. 实际待定行动者因此变为优势方。
4. 若生命差达到 2 点，触发补偿。
5. 弱势方临时取得补偿操作权，选择并立即使用一件补偿道具。
6. 补偿结束后，正常行动权仍交给第 3 步确定的优势方。

这表示弱势方虽然可以操作补偿道具，但没有取回被手铐跳过的普通回合，也不能在补偿期间开枪或使用库存道具。

### 4.2 优势方被铐住

如果回合结束后原本应轮到优势方，但优势方被手铐跳过，实际待定行动者变成弱势方，则不触发补偿。弱势方已经通过手铐结果取得下一回合的正常行动权，不再额外获得补偿。

### 4.3 反面硬币的例外

“反面硬币”可以明确把下一回合的首个正常行动权改为弱势方。它是唯一能够在补偿结算中改变待定行动者的首发道具。

弱势方因手铐刚被跳过、又在补偿中使用反面硬币时，结果仍是弱势方取得下一回合先手。原因是旧手铐已经在判定待定行动者时消耗，反面硬币属于之后发生的新规则效果。这个效果是补偿池中专门用于反制连续压制的翻盘选项，不视为手铐失效。

## 5. 完整流程

```text
最后一颗子弹被消耗
→ 结算伤害与死亡
→ 对局未结束
→ 结算手铐跳过并确定待定行动者
→ 检查生命差与待定行动者
→ 若不满足条件，直接开始正常装填流程
→ 若满足条件，暂停装填与普通道具补发
→ 保存待定行动者
→ 弱势方获得补偿操作权
→ 进行一次事件级 7% 稀有判定
→ 生成两个补偿选项并升起补偿陷阱框
→ 弱势方选择其中一个并立即使用
→ 未选道具收回，两个补偿陷阱框关闭
→ 结算所选补偿效果
→ 生成并装填新一轮子弹
→ 补发普通道具
→ 应用需要在装填后生效的补偿信息
→ 将正常行动权交给保存的待定行动者
```

如果所选道具明确改变下一回合先手，例如“反面硬币”，则在恢复正常行动权前覆盖保存的待定行动者。

如果所选道具进入“随机死亡模式”，正常装填、普通道具补发和原待定行动者恢复流程全部取消，改由随机死亡模式自己的开场流程接管。

## 6. 补偿陷阱框与交互

### 6.1 桌面位置

- 在枪的左边、桌面靠左的中心线附近增加两个补偿陷阱框。
- 单个补偿陷阱框与现有普通道具陷阱框大小一致。
- 两个框属于独立设施，不占用双方的 8 个普通道具槽位。
- 平时完全收在桌面下方；只有补偿事件发生时才一起升起。
- 两个框不能遮挡枪、生命牌、普通道具或射击目标区域。
- 白天和黑夜均需有足够的局部照明，使双方能辨认两个补偿道具。

### 6.2 双方可见性

- 单人模式中，玩家和 AI 看到同一组公开候选。
- 多人模式中，两名玩家看到同一组由服务端生成的候选及相同的选择结果。
- 只有弱势方可以点击、确认补偿道具。
- 优势方可以查看名称和公开说明，但所有确认操作均为禁用状态。
- 具体私密信息仍只发送给使用者，例如“透膛底片”看到的子弹顺序。

### 6.3 强制立即使用

- 补偿道具不能拿走、储存、交换或放入普通道具栏。
- 选择即代表使用；不设置“先拿着，之后再用”。
- 选中道具完成动画并结算，未选道具同时翻转回桌面下方。
- 补偿窗口期间，枪和普通道具全部锁定，避免把补偿操作权误当成正常行动权。

## 7. 候选生成与 7% 稀有判定

每次触发补偿时，只进行一次事件级稀有判定：

1. 生成一个独立随机值。
2. 有 7% 概率判定成功：
   - 从左右两个槽位中随机选择一个放置“插电板”；
   - 另一个槽位从当时合法的普通补偿池中抽取；
   - 同一次补偿绝不会出现两个插电板。
3. 有 93% 概率判定失败：
   - 从当时合法的普通补偿池中抽取两个不同道具；
   - 两个槽位不出现重复道具。

“7%”是一次补偿事件中出现插电板的总概率，不是每个槽位分别拥有 7% 概率。因此插电板的实际出现率固定为 7%，不会因为有两个槽位而变成 13.51%。

候选在生成前必须排除当前局面中完全无效的道具，不能让弱势方被迫在两个废选项中选择。候选一旦生成，就写入权威游戏状态；刷新或断线重连不能重新抽取候选。

## 8. 首发补偿池

| 名称 | 类型 | 核心作用 |
| --- | --- | --- |
| 电灯遥控器 | 普通补偿 | 强制下一回合进入黑夜 |
| 折叠水果小刀 | 普通补偿 | 将优势方的生命上限切到其当前生命值 |
| 备用保险丝 | 普通补偿 | 抵消弱势方下一回合首次受到的 1 点枪械伤害 |
| 透膛底片 | 普通补偿 | 私下看见新弹仓最前面的两颗子弹 |
| 反面硬币 | 普通补偿 | 将下一回合先手改为弱势方 |
| 插电板 | 7% 稀有补偿 | 切断桌面系统并进入随机死亡模式 |

“插电板”不加入普通补偿池，只能通过每次补偿事件开头的 7% 稀有判定出现。

## 9. 电灯遥控器

**作用**：点击遥控器后，强制即将开始的下一回合进入黑夜。

**规则**：

- 常规模式：仅下一回合进入黑夜；该回合结束后恢复常规模式原本的白天规则。
- 挑战模式：覆盖下一回合原本的随机昼夜结果；再下一个回合继续使用挑战模式的正常随机昼夜规则。
- 黑夜模式或其他永久黑夜状态：遥控器没有有效作用，生成候选时排除。
- 如果某种效果已经把下一回合锁定为黑夜，遥控器同样排除，避免重复提供无效选项。

**进入黑夜时的完整结算**：

- 回收双方库存中的全部肾上腺素。
- 清除尚未完成的肾上腺素偷取选择状态。
- 下一回合的普通道具补发池中排除肾上腺素。
- 双方看到对应的肾上腺素模型翻转并收回。
- 切换黑夜灯光、环境表现和黑夜音乐。

遥控器改变的是下一整个昼夜回合，而不是只关闭几秒灯光。

## 10. 折叠水果小刀

**作用**：砍坏优势方的生命牌，将优势方的个人生命上限永久降低到其当前生命值。

示例：优势方当前为 5/8 点生命，使用后变为 5/5；之后香烟和过期药物最多只能把优势方恢复到 5 点。

**规则**：

- 不造成即时伤害，不改变优势方当前生命值。
- 只修改本局中目标一方的个人生命上限，不修改弱势方上限。
- 效果持续到本局结束。
- 如果以后再次满足补偿条件，且目标当前生命值又低于已经被切过的上限，可以再次降低上限。
- 如果目标当前生命值已经等于其个人生命上限，此时使用没有效果，因此生成候选时排除水果小刀。
- 不需要额外编写“最低只能切到 2”的硬限制。双方都存活时弱势方至少有 1 点生命；生命差至少为 2 意味着优势方至少有 3 点生命。若优势方只剩 2 点而仍要满足 2 点差，弱势方已经为 0 点并且对局早已结束，根本不会进入补偿流程。因此合法触发条件天然形成了下限。
- 满血类成就应以当事人被修改后的个人生命上限为准，而不是继续使用开局时的公共上限。

**表现**：弱势方拿起折叠小刀，刀片弹开，划过优势方生命牌；生命牌外框或多余刻度被切落，新的上限清楚显示。该动作不能表现成直接砍伤角色，因为它修改的是生命容量，不是造成伤害。

## 11. 备用保险丝

**作用**：下一回合中，弱势方第一次受到枪械伤害时，将该次伤害减少 1 点。

**规则**：

- 普通实弹的 1 点伤害被完全抵消。
- 使用手锯后的 2 点实弹伤害降低为 1 点。
- 无论子弹由对手射来还是弱势方对自己射击，只要弱势方实际将受到枪械伤害，都可以触发。
- 不抵消过期药物失败、自定义事件或其他非枪械生命损失。
- 只触发一次；触发后立即消耗。
- 如果下一回合结束时仍未触发，则自动失效，不带入更后面的回合。
- 弱势方已经存在未消耗的同类保险丝效果时，不再生成该候选。

**表现**：使用时将保险丝插进生命牌或桌面供电盒。触发时发出短促电火花，伤害数字先出现后减少 1；未触发而过期时，保险丝熔断变黑并随回合结束收回。

## 12. 透膛底片

**作用**：新一轮子弹完成内部生成后，私下向弱势方揭示最前面的两颗子弹及其准确顺序。

**规则**：

- 补偿阶段先使用底片，实际信息在随后新弹仓生成时显示。
- 显示格式必须包含位置和类型，例如“第 1 发：空弹；第 2 发：实弹”，不能只用颜色区分。
- 结果只有弱势方可见；优势方只能知道对手使用了透膛底片，不能看到内容。
- 记录随射击或啤酒退弹正常前移；对应子弹被消耗后删除记录。
- 这两颗子弹在被消耗前，放大镜等信息道具应复用同一份已知信息，不能产生矛盾结果。
- 进入随机死亡模式时立即清除底片等待状态和全部底片记录。

**表现**：弱势方把半透明底片举到桌灯或枪膛方向，装弹结束后底片上显现两格私密结果。对手视角只显示无法辨认内容的背面。

## 13. 反面硬币

**作用**：将下一回合的首个正常行动权改为弱势方。

**规则**：

- 使用后覆盖补偿触发前保存的待定行动者。
- 只改变下一回合的第一位行动者，不提供额外行动次数。
- 第一位行动者开始操作后，后续交权继续遵守射击、空弹自射和手铐等正常规则。
- 旧手铐已在补偿触发判定中消耗时，不会再次跳过反面硬币取得的先手。
- 如果未来存在另一项已经锁定下一回合先手的不可覆盖效果，应在生成候选时排除反面硬币。

**表现**：弱势方抛起一枚两面都像反面的旧硬币，硬币落在枪旁，枪或行动灯转向弱势方一侧。效果结算后硬币掉进桌缝，不进入库存。

## 14. 插电板与随机死亡模式

### 14.1 使用表现

插电板只通过 7% 稀有判定出现。弱势方选择后，角色拔掉插头，按以下顺序表现：

1. 所有普通道具陷阱框同时翻转回桌面下方。
2. 两个补偿陷阱框关闭。
3. 双方绿色生命显示逐渐熄灭，而不是瞬间替换为普通数字 UI。
4. 弹药展示机构停止升起，后续不再公开翻出子弹模型。
5. 主灯断电，只保留低亮度应急光、枪口闪光和必要的轮廓光。
6. 屏幕弹出“进入随机死亡模式”提示。

### 14.2 模式规则

- 随机死亡模式一旦进入，持续到本局结束，不能恢复常规昼夜流程。
- 双方当前生命值和个人生命上限都重置为 2。
- 精确生命数字不再显示；双方通过中弹次数和受击反馈判断剩余生命。
- 双方所有普通道具永久清空，之后不再补发普通道具。
- 之后不再触发补偿机制。
- 清除手铐、手锯增伤、备用保险丝、子弹信息记录、肾上腺素选择及其他尚未结算的临时状态。
- 彻底停用原有弹仓，不再后台生成或消耗成批子弹，也不会发生换弹。
- 每次扣动扳机时独立随机判定一次：50% 为实弹、50% 为空弹；此前任何一枪的结果都不影响下一枪。
- 右上角整块弹仓信息隐藏；子弹模型和装弹陷阱机构不再翻出。枪的射击、空弹声音和命中结果仍正常表现。
- 实弹每次按正常基础规则造成伤害；生命降到 0 的一方死亡。
- 对自己射出空弹继续行动、其他射击交权等核心规则保持不变。
- 因全部道具已经断电，随机死亡模式中不再存在手锯增伤、治疗、查弹、退弹、偷取或手铐效果。

随机死亡模式是一段对双方都危险的对称终局。它不是“弱势方直接获胜”，而是让原有资源、血量上限、弹仓和信息优势全部断电归零，只留下枪、每次独立的 50% 判定和两条命。

## 15. AI 使用规则

AI 成为弱势方时，也必须经过相同候选生成和立即使用流程，不能读取未公开的未来随机结果。

AI 选择补偿道具时可考虑：

- 下一回合先手是否属于对手。
- 双方当前生命与个人生命上限。
- 对手可用的手锯、治疗和信息道具。
- 当前模式与下一回合是否已经被锁定为黑夜。
- 备用保险丝能否避免近期致死伤害。
- 反面硬币能否取得关键先手。
- 水果小刀能削掉多少实际可恢复空间。

AI 不得因为知道完整弹仓顺序而高估透膛底片，也不得预知插电板之外的随机死亡模式弹仓。

## 16. 多人模式与断线重连

- 补偿触发、7% 稀有判定、两个候选、选择结果和全部效果均由服务端权威结算。
- 客户端只发送“选择左侧或右侧补偿道具”的请求，不能自行指定道具 ID 或随机结果。
- 服务端必须再次验证提交者确为弱势方、当前处于补偿阶段且所选槽位有效。
- 候选和补偿阶段写入房间状态；刷新或重连后继续显示同一组候选，不能重新抽取 7%。
- 两名玩家都收到公开的使用动画和公开结果，私密弹药信息仅发送给合法接收者。
- 补偿动画期间双方普通输入锁定；动画异常或资源加载失败不能阻止服务端继续到下一阶段。

多人模式建议为补偿选择设置 30 秒操作时限。超时后由服务端从本次出现的普通补偿选项中自动选择；如果其中包含插电板，超时逻辑不得自动选择插电板。若唯一合法选项为插电板，则跳过插电板并使用预先生成的普通后备项。该超时规则在正式实现前仍可根据房间节奏调整。

## 17. 必要的状态结构

实现时至少需要能表达以下状态；字段名可以调整，但含义不能省略：

  maxHp: { player: 6, ai: 4 },
  phase: "playing" | "compensation" | "reloading" | "random_death",

    advantaged: "player" | "ai",
    pendingTurn: "player" | "ai",

    forceNextLighting: null | "night",

水果小刀要求生命上限从当前的单一公共数值改为双方各自独立的数值。所有治疗上限、生命牌、AI 评估、满血成就、状态复制、服务端视图和测试都必须改为读取当事人的个人上限。

## 18. 关键边界情况

- 最后一发导致任何一方死亡：直接结束，不触发补偿。
- 最后一发后生命差小于 2：直接装填。
- 生命差达到 2，但下一行动者是弱势方：直接装填，不触发补偿。
- 弱势方被手铐跳过，实际轮到优势方：消耗手铐并触发补偿。
- 优势方被手铐跳过，实际轮到弱势方：消耗手铐但不触发补偿。
- 最后一发由啤酒退出：和射击耗尽弹仓采用同一补偿判断。
- 补偿期间断线：保留候选与剩余阶段，重连后继续，不重新随机。
- 补偿期间投降或房间结束：立即取消补偿并进入终局。
- 黑夜候选池：排除已经无效的电灯遥控器。
- 优势方当前生命等于个人上限：排除折叠水果小刀。
- 已有未消耗保险丝：排除备用保险丝。
- 选择透膛底片后进入插电板模式是不可能的，因为同次补偿只能选择一件道具；其他效果若强制进入随机死亡模式，则清除底片状态。
- 插电板出现但未被选择：按普通未选道具收回，不进入随机死亡模式。

## 19. 首版验收标准

- 回合结束后严格按死亡、手铐、生命差、实际行动者的顺序判断补偿。
- 弱势方被铐住时可以获得并操作补偿，但默认不会额外得到正常射击回合。
- 两个补偿槽位只在补偿阶段升起，大小、位置、光照和可点击区域正确。
- 新子弹和普通道具在补偿结算完成前不会生成或翻出。
- 每次补偿只进行一次 7% 稀有判定，插电板总出现率为 7%，且不会同时出现两个。
- 非稀有候选不重复，也不会出现当前完全无效的道具。
- 六件首发道具均按本文规则生效，且补偿道具不会进入普通库存。
- 水果小刀正确修改个人生命上限，治疗、生命显示和满血成就读取新上限。
- 电灯遥控器进入黑夜时完整回收双方肾上腺素。
- 透膛底片的结果不会泄露给对手。
- 反面硬币是首发池中唯一默认改变下一回合先手的补偿道具。
- 插电板正确清空桌面状态、关闭生命与弹药显示，并进入双方两条命的随机死亡模式。
- 多人刷新和断线重连不会重抽候选、重滚 7% 或重复结算效果。
- 所有随机结果只生成一次，逻辑状态、事件日志和三维动画使用同一份结算结果。
