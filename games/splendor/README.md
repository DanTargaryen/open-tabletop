# 璀璨宝石 · 宝可梦特别款

已发行《Splendor: Pokémon》特别版规则的非官方网页实现。支持 2–4 个座位，单人对战本地 AI，或通过 Node / Worker + D1 服务与好友联机。与经典版不同：本作使用进化、特殊宝可梦卡与 18 分终局，没有贵族。

在仓库根目录运行 `npm start`，打开 `/games/splendor/index.html`（单人）或 `/games/splendor/online.html`（好友房）。没有 npm 运行依赖。

线上试玩：[单人冒险](https://velvet-poker-friends.linming-dracarys.chatgpt.site/games/splendor/) · [好友联机](https://velvet-poker-friends.linming-dracarys.chatgpt.site/games/splendor/online)。托管于现有 Sites 域名，好友房数据由远端 D1 保存。

## 怎么玩

1. 选择人数与昵称。单人模式的其余座位为 AI；好友房只有你一人时可点“一个人开局”，自动补齐 1–3 位 AI；多人房仍需真人准备，未满员时由房主选择补 AI。
2. 点击供应区选择精灵球并确认拿取，或点击宝可梦卡查看费用、捕捉或预留。点击一至三级牌库可盲预留。
3. 超出十枚球时先选择归还。若符合条件，右侧会出现进化选项；每回合至多一次，也可以放弃。进化可以使用自己预留的下一阶卡。
4. 达到十八分后补完当前轮，按奖杯、进化次数、场上宝可梦数量依次比较。完局后可以再开一局。

大师球可以替代普通球。捕捉弹窗中的“调整支付方式”允许保留某种普通球，改用大师球支付。特殊卡的必需大师球不能由普通球或永久加成替代。

页面下方的个人区域显示六种球的持有数量、总数与超额提示，并单独列出永久加成。默认使用舒适布局：普通展示卡、已捕捉卡和预留卡使用约 232px 高的大卡，角色图片、卡名、费用和进化条件完整显示。个人区横跨牌桌，卡牌自然换行；整页支持上下滚动，队伍区不再使用独立的窄滚动条。点击已捕捉卡可查看详情或回放入队效果。

宽屏保留每级四张公共卡；620px 以下的窄窗口改为每级两列、两行，方便看清图片和文字。操作面板随页面滚动，不会覆盖下方的个人卡区。右上角“紧凑布局”可切回一屏优先的小卡模式，再点“舒适布局”恢复。布局偏好使用独立的 v2 键保存，默认优先可读性，不修改游戏存档。冒险记录仍可展开查看。

## 捕捉反馈

捕捉成功后，角色会弹出并飞向队伍，随后显示获得的永久加成或奖杯；进化显示新旧卡替换后的净收益。对手的捕捉以较轻的提示展示。动效不拦截点击，也不改变回合。

点击自己已经拥有的卡，可以选择“回放加入队伍动效”，无需再次捕捉或消耗筹码。系统启用减少动态效果时，使用静态成功提示；音效遵循页面原有开关。首次加载、刷新恢复、重复状态和被拒绝的动作不会自动播放成功效果。

## 运行与联机

`/api/splendor` 是独立接口。Node 模式将数据保存在 `splendor-rooms.json`，Worker 模式将数据保存在独立 D1 表中；两者均与扑克分开，运行数据不属于公开资源。`npm run lan` 可提供局域网访问，公网可使用 Node + HTTPS 或 Sites / Workers + D1。

房间使用服务端权威状态、随机洗牌、SHA-256 身份摘要、版本检查、请求编号去重和存储 CAS。每次回复只包含当前玩家可见的信息：不发送牌库顺序、他人的预留卡身份或训练师板卡面。所有人的持球、场上卡和数量公开。

浏览器保留独立的宝可梦版命名空间。刷新恢复需要原浏览器身份和未过期房间；主动离开会撤销座位身份，并在对局中交由 AI 接手。房主离开后转交给剩余真人。所有真人离开则房间失效。房间活动 TTL 为 24 小时。

联机约定：先手随机；真人每个待处理动作限时 120 秒，超时由本地策略执行一个合法决定。AI 默认间隔 900 毫秒。推进由已认证的请求触发，无人请求时不会在后台连续代打。无合法主动作时允许跳过；三层判定仍同分时共享胜利。上述数字化约定与实体规则分开。

单人 AI 有均衡、奖杯竞速、进化三个权重配置，使用可见状态选择合法动作；不读取对手预留或牌库，不调用外部模型。它们是启发式策略，并非经过竞技强度评级的模型。

## 验证与边界

- 根目录 `npm test` 自动发现本游戏的规则、房间与真实 HTTP 测试。
- 自动对局覆盖 2、3、4 人各 12 个固定种子；逐步检查 90 张卡、精灵球、加成和分数。
- 数值卡池是 **35 / 30 / 15 / 5 / 5**，共 90 张、55 种。来源为社区转录；已核对分布和引用完整性，**尚未逐张对照实体盒**。
- 本地和静态单人都能运行。Cloudflare 适配器通过独立 `splendor_rooms`、`splendor_limits` 表支持宝可梦联机；需要应用 `deploy/cloudflare/migrations/`。健康检查实际查询表，缺少绑定或迁移时返回 503。静态构建本身不代表后端已部署。
- 公网已完成两身份建房、加入、准备、操作及隐私检查；这仍不等于两台实体设备的长时间对战。
